CapyBreak

Accessibility

Features designed to make the movement timer easier to use with the keyboard and macOS assistive technologies.

The exact Mac App Store accessibility labels will be selected only after their required manual tests pass on the submitted build.

Implemented support

  • Native, labelled Yes and No controls with a spoken selected state.
  • Keyboard navigation that keeps focus and the visible answer selection aligned.
  • A high-priority VoiceOver announcement when the movement countdown succeeds.
  • Reduce Motion support that replaces the repeating exercise animation with a still pose.
  • VoiceOver actions that move the draggable capybara reminder left, right, up, down or back to the centre.
  • Contextual spoken labels for timer information and bulk application or website actions.
  • State text and menu bar silhouettes that do not depend on colour alone.
  • A semantic accent colour chosen for readable contrast on light and dark system backgrounds.

Feedback

If an accessibility feature does not work as expected, email hello@alfreds.me. Include the macOS version, assistive technology and shortest steps that reproduce the problem.
